Roc GUI is a small native GUI platform built around one predictable loop:
state is rendered into elements, user events produce actions, and actions
produce the next state. This manual takes an application from its first window
through semantic specifications and repeatable scaling measurements.

== Choose a path

New to Roc GUI:: Read <<_what_you_build>>, then follow <<_getting_started>> to
build the counter and a minimal application.
Application author:: Continue through <<_building_an_application>> for the
state/action/render model, elements, layout, and local state boundaries. Use
<<_specifying_behaviour>> to test through semantic user actions.
Performance investigator:: Start with <<_measuring_scaling>>, then use
<<_understanding_captures>> to choose and interpret SQLite evidence views.
Platform contributor:: Read <<_contributor_architecture>> before
<<_contributing>>. These chapters cover host ownership, event routing, evidence
ownership, validation, and feature completeness.
