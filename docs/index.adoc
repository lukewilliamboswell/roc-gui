[.lead]
Roc GUI is a small native GUI platform built around one predictable loop:
state is rendered into elements, user events produce actions, and actions
produce the next state. This manual takes an application from its first window
through specifications that verify it, and on to repeatable scaling
measurements.

== Choose a path

New to Roc GUI:: Read <<_what_you_build>>, then follow <<_getting_started>> to
build the counter and a minimal application.
Application author:: Continue through <<_building_an_application>> for the
state/action/render model, elements, layout, and local state boundaries.
Verifying your own application:: Read <<_testing_your_application>>. The
executable you build runs both specification runners itself, so checking
behaviour, layout, and appearance needs no test framework and no second build.
<<_specification_reference>> has the complete step vocabulary.
Advanced application author:: Read <<_how_roc_gui_works>> for the rendering and
event lifecycles, boundary replacement model, and comparison with other GUI
architectures.
Performance investigator:: Start with <<_measuring_scaling>>, then use
<<_understanding_captures>> to choose and interpret SQLite evidence views.
Platform contributor:: Read <<_how_roc_gui_works>> before
<<_resource_access_and_trusted_grants>> and <<_contributing>>. These chapters
cover host ownership, event routing, evidence ownership, validation, and feature
completeness.
