= Troubleshooting

== `roc build` cannot find `libhost.a`

Run `python3 build.py` from the repository root. It creates
`platform/targets/x64glibc/libhost.a`, the archive selected by the platform's
`x64glibc` target. Rebuild it after Rust host changes.

== The Windows build rejects the SDK's shader tools

`build.py` compiles GPUI's shaders with the Windows SDK's `fxc.exe` and its
`d3dcompiler_47.dll`. CI and release builds admit only the reviewed pair, by
hash and signing certificate, recorded in `scripts/windows_gnu_build.py`. A
development machine receives SDK servicing updates that re-sign and re-hash
that pair, so a local build admits any validly Microsoft-signed pair instead
and records the identities it loaded; it says so as it builds. Set
`ROC_GUI_PINNED_SHADER_TOOLS=1` to require the reviewed pins locally as well.
Either way an unsigned or altered pair is refused, and a refusal names the SDK
directory it examined.

== The Roc compiler version does not match

Use the nightly named in the `app` header and in `platform/main.roc`. The
example applications pin the same nightly as the platform. A different compiler
may fail before it checks application code.

== The executable rejects an argument

Host arguments belong after the executable name. Supported options include
`--host-help`, `--host-run-spec PATH`, `--host-run-window-spec PATH`,
`--host-smoke`, `--host-stats-record`, and the `--host-stats-*=VALUE` recording
controls described in the observatory chapter. `--host-help` lists them all.
The host rejects unknown arguments.

== A click locator is missing or ambiguous

Check the `label` field passed to `Elem.button`. A role locator uses this
semantic name, not the visible text. Names must be unique among the buttons
present at that step. If a preceding click replaced a boundary, locate
the new button by name rather than retaining an old host node identity.

== A specification passes but performance columns are `NULL`

Run `semantic_health` and `capture_health` first. If both are complete, `NULL`
means the selected backend did not perform or instrument that work. Semantic
headless runs do not open a window, so GPUI layout, paint, and presentation
cannot be inferred from them.

== A comparison is rejected

Compare captures for the same specification and benchmark policy, built for a
compatible target, backend, profile, recorder policy, and machine properties.
Generate both serially and use `--aa` to measure normal variation. The analyzer
rejects incomplete captures before calculating ratios.

== The documentation build cannot render diagrams

Run `python3 scripts/build_docs.py --pdf` with Docker available. The pinned
documentation image contains Asciidoctor, the PDF and diagram extensions,
Mermaid CLI, Chromium, and the source highlighters; none of these are installed
on the host.
