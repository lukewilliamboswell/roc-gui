# Icon notices

The SVG files in this directory come from [Lucide](https://lucide.dev), an open
icon set. Each file is redistributed here with one edit: the upstream
`stroke="currentColor"` is replaced by an explicit grey, because these files are
rendered from bytes and inherit no colour from the element around them. The
greys are neutral, so each icon carries only the weight its surface asks for and
leaves colour to the text beside it. Nothing else in any file is changed.
