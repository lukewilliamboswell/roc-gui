# Icon notices

The SVG file in this directory comes from [Lucide](https://lucide.dev), an open
icon set. It is redistributed here with one edit: the upstream
`stroke="currentColor"` is replaced by an explicit grey, because the file is
rendered from bytes and inherits no colour from the element around it. The grey
is neutral, so the mark carries only the weight the status strip asks for and
leaves colour to the sentence beside it. Nothing else in the file is changed.
